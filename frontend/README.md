# Taskify - Todo Chatbot Frontend

A Next.js frontend for the Taskify Todo Chatbot application with AI-powered task management.

## Deployment

This application is designed to be deployed on Vercel.

### Environment Variables

Before deploying, configure the following environment variables in your Vercel project:

- `NEXT_PUBLIC_API_URL` - The URL of your deployed backend API (e.g., `https://your-backend-app.onrender.com`)

### Deploy to Vercel

1. Connect your GitHub repository to Vercel
2. Import your project
3. Set the environment variables as mentioned above
4. Deploy!

## Features

- AI-powered chatbot for task management
- User authentication and authorization
- Task creation, editing, and deletion
- Responsive design for all devices
- Modern glassmorphism UI

## Tech Stack

- Next.js 14 with App Router
- React 18
- TypeScript
- Tailwind CSS
- Vercel for deployment
